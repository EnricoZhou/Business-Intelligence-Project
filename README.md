Financial Services Business Intelligence Project:
This individual project is designed to showcase the student's ability to analyze financial data using key data science techniques such as data acquisition, visualization, exploratory analysis of time series and portfolios, and return forecasting. Utilizing Python libraries like Pandas, Matplotlib, Numpy, Scikit-Learn, and StatsModels, the student can choose to analyze either six S&P 500 stocks from different sectors or six sectoral ETFs from the S&P 500 or MSCI USA for the period from May 31, 2014, to May 31, 2024. The deliverables include a Jupyter Notebook with well-documented code, a 10-15 minute presentation summarizing key findings, and a detailed report covering data summary, descriptive statistics, forecasting analysis, beta calculation, portfolio simulation, and overall data science insights.
